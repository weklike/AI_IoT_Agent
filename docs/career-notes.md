# 求职材料草案

以下只描述已实现的工程能力，不填写未经验证的真实模型或性能数字。投递前需本人阅读代码、完成演示并能解释取舍。

- 开发纯软件充电设备监控系统，使用三个独立 MQTT 客户端、FastAPI、SQLite 与 Vue 完成遥测、历史查询、场景回执及检修工单展示。
- 实现 message_id/启动序号双唯一约束、重复/冲突处理、乱序快照和独立新鲜度判定，覆盖 Broker 与进程重启恢复。
- 实现单 Agent 的四工具白名单、授权与证据检查、请求幂等、执行预算和提交边界恢复，区分 fixture 测试与真实模型效果。
