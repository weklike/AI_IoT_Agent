# 已知限制与验收边界

- 第一版仅单机、单用户演示，HTTP 与 MQTT 端口限本机；没有面向公网的鉴权、多租户或高可用设计。
- 三台软件设备及温度规则不代表真实硬件诊断、认证或安全控制能力。
- 一个 worker、一个 Agent 运行槽位；SQLite 适合本演示负载，WAL 不等于无锁。锁竞争明确报错，不无限重试。
- fixture 是演示脚本，不理解任意自然语言，不应以 fixture 案例数或结构断言通过数宣传真实模型效果。初轮 60 次 fixture 中 A06 的 3 次因先查状态而提前 NO_DATA，未完成案例所需历史工具，失败已保留。
- real 仅实现 Chat Completions 工具协议适配；当前本机代理的 gemini-3.8-flash-high 已验证工具往返与网页原问题查询；完整真实评测与人工结论另见进度，不推广为所有端点均兼容。
- 回环模型代理可选用独立宿主机 TCP 转发进程；当前 gemini-3.8-flash-high 回环配置继续使用该进程。WSL/主机重启后按 README 恢复，不改全局代理配置。
- 此前 deepseek-v4-flash 端点延迟不稳定：真实评测试跑 12/60 后因 8 个模型超时停止诊断；另 48 个明确 NOT_RUN。单次网页成功不代表整体效果达标，20 秒上限没有放宽。
- 当前没有真实人工语义复核或真人录屏；G3 不可判定 PASS。汇总脚本不会自动填写 reviewer，也不会把另一个模型当成人工。
- UI 部署构建可能提示图表 bundle 较大；首版优先保证真实链路与业务可解释性，不通过提高警告阈值掩盖体积。
- 数据模式尚处第一版开发期，没有跨历史发布版本的数据库迁移承诺；现有库不自动重置或覆盖。正式改变已部署模式时应补迁移。
- 工单只创建与查询，无派单、关闭或审核生命周期。没有任意重置入口；seed_demo 只初始化空库。
- 完整验收状态与未覆盖子断言以 artifacts/acceptance/results.json 和 docs/PROGRESS.md 为准；任务实现不能替代验收 PASS。

- 历史 NVIDIA 配置重试：状态工具执行成功，最终回答阶段 MODEL_TIMEOUT，完整 smoke 未通过。此前 gpt-5.6-luna 已通过独立 smoke；该模型已完成 60 次，自动检查 36/60，另有 3 次空数据流程不完整、6 次模型超时、15 次 HTTP 503。结束后最小请求恢复，但不能说明稳定；本轮未达标，人工复核仍待完成。

- `.env` 更新需要重新创建 Compose backend 才会作用于网页。独立 smoke 不会更新常驻容器；浏览器刷新会恢复旧失败 run，需要点击“开始新任务”。本次 Gemini 原问题网页复测 12.305s 通过，完整模型质量尚未验收。
